# Java Week 1 Assignment

This repository contains three Java projects completed as part of my Java Full Stack Development Internship at WeIntern.

## Projects

### 1. Library Management System
A console-based Java application to manage books in a library.

**Features:**
- Add and view books
- Search for books
- Issue and return books
- Remove books

### 2. Banking Application
A Java application demonstrating basic banking operations.

### 3. Java Collections Challenge
A Java program demonstrating the use of:
- ArrayList
- HashMap
- Queue

## Technologies Used

- Java Collections Framework
- Eclipse IDE
